# Refutation classifies rather than filters

Refutation looks for later work that addressed an Author-Stated Open Problem, and the
obvious design throws away every problem that somebody already solved. We reject that. A
final year project does not need an unsolved problem, it needs a defensible difference from
Prior Work, so a solved problem with a different approach is a legitimate project and often
the safest one. Refutation therefore returns one of three Verdicts, and each Verdict decides
which kind of Angle the problem becomes: Gap, Transfer, or Alternative.

## Consequences

Nothing is discarded for lack of novelty. The only reason to discard an Angle is a failed
Slice Condition or a failed Resolution Check.

Two rules keep this from degenerating into generic project ideas. Every Angle names the
Prior Work it differs from, with a citation. Every Angle's difference answers a Reported
Limitation that somebody actually wrote down. Without both rules, "the same thing in a
different language" passes.

The Backtest changes meaning. It no longer asks whether researchers later filled a
predicted Gap. It asks whether the Verdict was correct, measured per Verdict against what
is known today.
